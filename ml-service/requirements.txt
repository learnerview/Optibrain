#

#                  at the time of writing but is a fragile dependency that needs a C++
#                  toolchain in the image. Forecasting is currently done with
#                  statsmodels/sklearn. Add it only if the Prophet model is actually
#                  used, and pin the version.
#   tensorflow   - a ~600MB dependency. Nothing in this service imports it; it was
#                  left over from an abandoned deep-learning path.
#   torch        - same.
#   statsmodels  - currently unused; forecasting_service uses sklearn. Listed here
#                  rather than removed pending that cleanup, since it is a small,
#                  safe dependency if it is reintroduced.
#   matplotlib / seaborn / pyod - plotting and anomaly libraries. Not imported by the
#                  service at present.
#   mlflow       - model tracking. model_manager.py was removed; no import remains.
#   psycopg2-binary - no PostgreSQL connection is made.
#   google-generativeai - chat_service falls back to canned replies; the Gemini client
#                  is optional and not required to start.
